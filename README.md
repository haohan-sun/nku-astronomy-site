## 怎么加新内容

所有内容都在 **assets/js/data.js**，改这一个文件就行，不用碰 index.html。

### 加一张照片

1. 照片放进 `assets/img/gallery/`，文件名用英文或数字，比如 `15-orion.jpg`
2. 在 `gallery: [` 后面加一段：

~~~js
{
  src: "assets/img/gallery/15-orion.jpg", w: 1600, h: 1067,
  title: "猎户座大星云",
  date: "2026.12",
  place: "八里台校区",
  event: "冬季观测",
  author: "张三"
},
~~~

3. 保存刷新，点开大图就能看到这几项信息。

- `w` / `h` 是图片像素宽高，写对了加载时页面不跳。右键属性能看到。
- **不知道的项写 `""`，那一行自动不显示。**
- 建议长边 1600px、质量 80，单张 300KB 以内。
- 数组越靠前越先显示，新照片加在最前面。

### 改活动卡片的详情

活动卡片点开后是一个右侧抽屉，内容在 `details` 里，按 key 对应：

~~~js
details: {
  xinglong: {
    detail: "第一段，卡片里放不下的介绍",
    more: "第二段，补充说明",
    photos: ["assets/img/gallery/05-xinglong.jpg",
             "assets/img/gallery/14-xinglong-group.jpg"]
  }
}
~~~

六个 key 依次是 festival（天文节）、sidewalk（路边天文）、meteor（流星雨）、
xinglong（兴隆研学）、talks（讲座社课）、outreach（科普进校园），顺序跟页面上卡片一致。
照片写 1 到 3 张都行，第三张会自动占满一行。

### 加一条活动足迹

在 `journey: [` 后面加一行，同样是越前越新：

~~~js
{ time: "2027.03", title: "三月观测", note: "备注，可省略" },
~~~

### 改每月天象

`skyNotes` 里 1 到 12 月各一条，格式 `[标题, 正文, 标签]`，页面按当前月份自动显示。

### 改文案、改配色

- 文字：全在 `index.html`
- 配色：`assets/css/style.css` 顶部 `:root` 的 `--purple`（#8C0078 青莲紫）、`--purple-2`（浅紫，文字和图标）、`--purple-3`（最浅）
- 鼠标光晕：`.cursor-glow` 那几条规则，透明度在 `radial-gradient` 里调
- 苏宜星与生成星座：`style.css` 末尾那一段（`.suyi-*`、`.hero__make*`），注释里写了归属
- 安卡助手：同一段末尾的 `.anka*`，造型图是 `assets/img/anka.png`（透明底），对话逻辑在 `assets/js/anka-chat.js`

### 安卡助手（AI 小助手）

前端在 `assets/js/anka-chat.js`（一个 IIFE），后端在 `proxy/`（Cloudflare Worker）。

**页面里没有任何 Key。** 前端只有一个地址：

```js
var ANKA = {
  proxyUrl: "",   // 填上后端地址才会走模型；留空时用本地小问答
  model: "deepseek-v4-1-flash-261017",
  maxTokens: 220, temperature: 0.3, timeout: 25000,
  minGap: 5000, maxPerSession: 15, maxPerDay: 40,
  maxInput: 200, maxHistory: 6
};
```

- `proxyUrl` 为空：只答写死在文件里的几个常见问题（加入 / 活动 / 苏宜星 / 今晚看什么 / 器材 / 校区 / 会费 / 历史），不联网。
- `proxyUrl` 填好：请求发到 `proxy/worker.js`，Worker 拿环境变量里的 `ARK_KEY` 去调方舟，前端依然看不到 Key。
- Worker 会覆盖 system 提示词、钉死模型和 `max_tokens`、限制消息条数与单条长度、校验 `Origin`，所以就算有人拿钥匙串绕过前端，也改不了额度。

三分钟部署：

```bash
cd proxy
npx wrangler deploy                 # 首次会引导登录 Cloudflare
npx wrangler secret put ARK_KEY     # 粘贴方舟的 Key，只在 Cloudflare 上保存
```

部署完把输出的 `https://anka.<你的子域>.workers.dev` 填回 `anka-chat.js` 的 `proxyUrl`。`proxy/wrangler.toml` 里的 `ALLOW_ORIGIN` 改成正式域名（默认 `https://haohan-sun.github.io`）。

> 本地预览时 `proxyUrl` 留空即可；要联调就用 `npx wrangler dev`，把 `proxyUrl` 临时指到 `http://127.0.0.1:8787`。

### 更新苏宜星轨道数据

1. `suyi-data.js` 是 JPL SBDB 的轨道要素快照，换一份新解就直接替换那六个要素和 `epoch`；
2. `suyi-ephemeris.js` 是 Horizons 的每日状态矢量（每行 `[JD, x, y, z, vx, vy, vz]`），换时间范围时同步改 `suyi-orbit.js` 里的 `minMS` / `maxMS` 和 `index.html` 里日期控件的 `min` / `max`；
3. 参数栏的六项由 `suyi-orbit.js` 从 `suyi-data.js` 直接读，不用手改。

## 关于免费域名

没有永久免费、且属于你的一级域名。能长期不花钱的只有平台子域（pages.dev、github.io）和非营利二级域（eu.org、is-a.dev）。

微软确实在 Azure App Service 上送过免费自定义域名（和 Freenom 合作那批 .tk），现在已结束；今天微软只给 `*.azurewebsites.net` 这类平台子域。Freenom 的 .tk 从 2023 年起停发并回收，别用。真能白嫖到像样域名的只剩 GitHub 学生包（Namecheap 送 .me 一年）。

建议：先 pages.dev 上线 → 问学校能不能批 `xxx.nankai.edu.cn` → 真想要独立域名一年几十块，换域名不用改代码。
